Knock is a plugin in Cursor. Open the listing and click Add to Cursor, or run `/add-plugin knock` in a Cursor chat.

The same listing is available in [Grok Bot](/ai/plugins/grok-bot). The plugin runs on the [Knock MCP server](/ai/mcp-server).
