Knock is a plugin in Cursor. Add it from the listing, or run `/add-plugin knock` in a Cursor chat. The same plugin is available in [Grok Bot](/ai/plugins/grok-bot).

The plugin runs on the [Knock MCP server](/ai/mcp-server) and can use the [Knock agent](/ai/agent). You do not need a local setup or a service token. Sign in with your Knock account, and Cursor picks up tools for the resources in your workspace.
