Knock is a plugin in Cursor. Add it from the listing, or run `/add-plugin knock` in a Cursor chat.

The same plugin is available in [Grok Bot](/ai/plugins/grok-bot). The plugin runs on the [Knock MCP server](/ai/mcp-server).
