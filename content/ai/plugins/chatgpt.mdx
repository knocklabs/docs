[Install ChatGPT plugin](https://chatgpt.com/plugins/plugin_asdk_app_6a8dddd50424819196928510eff4c70f)

Knock is a plugin in ChatGPT and Codex. Prompt either one to build and manage workflows, [broadcasts](/concepts/broadcasts), [guides](/concepts/guides), templates, and audiences.

The plugin includes skills for engagement work such as win-back, onboarding, growth, and improving the messaging you send. It runs on the [Knock MCP server](/ai/mcp-server) and can use the [Knock agent](/ai/agent). You do not need a local setup or a service token. Sign in with an existing Knock account, or create one during install.

In Codex, you can stay in the agent you use to write product code while you build the email and in-app messaging that ships with it.

## What you can do

- **Build workflows from a prompt.** Ask for a welcome sequence, and ChatGPT or Codex assembles the steps, templates, and conditions.
- **Rework copy across channels.** Point either one at existing workflows and ask it to tighten subject lines or adapt an email template for SMS and push.
- **Audit what you send.** Ask which workflows have gone quiet, where errors are occurring, or which templates use outdated branding.
- **Plan before you build.** Talk through a lifecycle program, then turn the plan into resources once you are happy with it.
- **Debug a delivery.** Pull message logs for a recipient to see what sent, what rendered, and where a workflow run stopped.

The plugin writes to your Knock account, so the result is a resource your team can review, edit, and send.

## Guardrails

- **Changes land in development.** The plugin creates versioned resources. Review them in the dashboard, then commit and promote them on your own schedule.
- **Nothing gets deleted.** The MCP server has no delete tools, so an agent cannot remove a workflow, template, or audience.
- **Access follows the signed-in user.** The plugin uses that person's Knock permissions.
- **You choose the surface area.** Enable only the capabilities a task needs, and leave the rest off.

## Get started

Open the [Knock listing](https://chatgpt.com/plugins/plugin_asdk_app_6a8dddd50424819196928510eff4c70f), click Install plugin, and sign in with your Knock account. Then choose which capabilities to grant.

In Codex, install it from the Plugins tab in the ChatGPT desktop app, or run `/plugins` in Codex CLI. Start a new session after you install so the Knock skills and tools load.
