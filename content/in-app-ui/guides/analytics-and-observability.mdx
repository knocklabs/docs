Use guide analytics to measure how each guide performs and monitor engagement. You can access analytics in the Knock dashboard, or export guide data to your own systems. Guide analytics are based on the engagement events your application sends to Knock, either through Knock's prebuilt components or by [tracking engagement](/in-app-ui/guides/handling-engagement#tracking-guide-engagement) in custom components.

## Guide metrics

Use guide metrics to see how many users in a guide's audience have seen, interacted with, or archived it. Each guide's **Overview** tab includes an analytics summary that highlights key metrics over the last N days, based on your account's [retention period](/manage-your-account/data-retention).

Guide overview metrics include:

- **Audience**. The total number of users in the target audience for this guide.
- **Seen**. The number of users for whom this guide is marked as seen.
- **Interacted**. The number of users who interacted with this guide.
- **Archived**. The number of users who archived or dismissed this guide.

You can also view analytics across all guides in the **Observability** > **Analytics** section, where you can filter and group by guide key to compare performance across different guides.

## Guide activity

The **Activity** tab lists the guide's [message events](/send-notifications/message-statuses#message-events) as they happen, newest first. For example, it shows each time a user sees, reads, interacts with, or archives the guide, as your application reports that engagement. Each row shows the event type, the recipient, and when the event happened. The tab isn't available in branch environments.

<Image
  src="/images/in-app-ui/GuideActivity.png"
  alt="Guide Activity tab listing interacted, read, seen, delivered, sent, and archived events with each event's recipient and timestamp"
  width={699}
  height={766}

/>

New events appear at the top of the list as users engage with the guide. The list pauses when you select an event or go to another page of the list, so rows stay in place while you read. Use the controls next to **Filter** to pause streaming, refresh the list once, or start streaming again from the newest events.

Select **Filter** to narrow the list by recipient, event type, tenant, or date. The list starts with the last 7 days of events. It can go back as far as your account's [data retention period](/manage-your-account/data-retention), up to 90 days.

Select an event to view its recipient, message ID, tenant, guide, and environment. Below those, a timeline shows every event on that message. An interacted event in the timeline includes any metadata your application [passed with the interaction](/in-app-ui/guides/handling-engagement#tracking-metadata-associated-with-guide-engagement). Select **View message** to open the message detail view.

## Message logs

You can access message details for guides through the **Messages** tab of each guide in the Knock dashboard, or via **Observability** > **Messages**. In the messages table, you can identify:

- **Engagement status**. Current [engagement state](/send-notifications/message-statuses#engagement-status) (seen, archived, etc.) per recipient.
- **Recipient information**. Which users received the guide and when.
- **Message timeline**. Creation and engagement timestamps for each guide message.

To read guide engagement through the API, list your guide channel's messages with the [messages API](/api-reference/messages/list) and use each message's `source.key` to tell guides apart. For one user's engagement, use the [guides API](/api-reference/users/guides).

## Exporting guide data

Guide message events are included in Knock's [available integrations](/integrations/extensions/overview) with analytics platforms, enabling you to track guide engagement alongside your other product data.

Customers using [warehouse export](/integrations/extensions/warehouse-export) can also access guide analytics data in the exported messages table. Guide messages can be identified by the presence of a `guide_id` and `guide_key`, which allows you to filter and analyze guide-specific message data in your data warehouse.
