<Section path="/warehouse">
<ContentColumn>

Warehouse commands enable you to read the [warehouses](/integrations/sources/syncs#manage-a-warehouse) connected to your account from the CLI. A warehouse is one database in your data warehouse that Knock reads from. Every environment shares it.

The CLI reads warehouses but doesn't create or change them. Add a warehouse and change its connection from the dashboard under **Platform** > **Sources**. To manage the syncs that read from a warehouse, use the [warehouse sync commands](/cli/warehouse-sync).

</ContentColumn>
</Section>

<Section title="knock warehouse list [flags]" path="/warehouse/list">
<ContentColumn>

Display all warehouses connected to your account, with their type and connection status.

### Flags

<Attributes>
  <Attribute
    name="--environment"
    type="string"
    description="The environment to use. When omitted, the account's default environment is used. Every environment lists the same warehouses."
  />
  <Attribute
    name="--limit"
    type="number"
    description="The total number to fetch per page."
  />
  <Attribute
    name="--after"
    type="string"
    description="Fetches all entries after this cursor."
  />
  <Attribute
    name="--before"
    type="string"
    description="Fetches all entries before this cursor."
  />
  <Attribute name="--json" type="string" description="Format output as json." />
</Attributes>

</ContentColumn>
<ExampleColumn>

```bash title="Basic usage"
knock warehouse list
```

</ExampleColumn>
</Section>

<Section title="knock warehouse get <warehouse_key> [flags]" path="/warehouse/get">
<ContentColumn>

Display a single warehouse, including its connection settings and connection status. Passwords and keys are never returned.

### Flags

<Attributes>
  <Attribute
    name="--environment"
    type="string"
    description="The environment to use. When omitted, the account's default environment is used."
  />
  <Attribute name="--json" type="string" description="Format output as json." />
</Attributes>

</ContentColumn>
<ExampleColumn>

```bash title="Basic usage"
knock warehouse get analytics
```

</ExampleColumn>
</Section>
