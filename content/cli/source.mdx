<Section path="/source">
<ContentColumn>

Source commands enable you to view the [sources](/integrations/sources/overview) in your Knock account from the CLI.

</ContentColumn>
</Section>

<Section title="knock source list [flags]" path="/source/list">
<ContentColumn>

Display all sources for an environment. Use an `--environment` flag to specify the target environment; if omitted, the Knock CLI uses the account's default environment.

### Flags

<Attributes>
  <Attribute
    name="--environment"
    type="string"
    description="The environment to use. When omitted, the account's default environment is used."
  />
  <Attribute
    name="--limit"
    type="number"
    description="The total number to fetch per page."
  />
  <Attribute
    name="--after"
    type="string"
    description="Fetches all entries after this cursor."
  />
  <Attribute
    name="--before"
    type="string"
    description="Fetches all entries before this cursor."
  />
  <Attribute name="--json" type="string" description="Format output as json." />
</Attributes>

</ContentColumn>
<ExampleColumn>

```bash title="Basic usage"
knock source list
```

```bash title="Pagination example"
knock source list --after=xxx
```

</ExampleColumn>
</Section>

<Section title="knock source get <source_key> [flags]" path="/source/get">
<ContentColumn>

Display a single source from an environment, using its source key.

Use an `--environment` flag to specify the target environment; if omitted, the Knock CLI uses the account's default environment.

### Flags

<Attributes>
  <Attribute
    name="--environment"
    type="string"
    description="The environment to use. When omitted, the account's default environment is used."
  />
  <Attribute name="--json" type="string" description="Format output as json." />
</Attributes>

</ContentColumn>
<ExampleColumn>

```bash title="Basic usage"
knock source get segment
```

```bash title="Get source in a different environment"
knock source get segment --environment=production
```

</ExampleColumn>
</Section>
