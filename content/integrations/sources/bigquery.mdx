Knock connects to BigQuery by impersonating a service account in your Google Cloud project, so there's no key or password to share. The warehouse's **Details** tab lists these steps with the values to copy. Every environment in your account can sync from the warehouse once it's connected.

## Add the warehouse

To add or edit a warehouse, you need the owner or admin [role](/manage-your-account/roles-and-permissions), or a custom permission group that's allowed to manage integrations.

1. Go to <a href="https://dashboard.knock.app/~/sources" target="_blank">**Platform** > **Sources**</a>.
2. Under **Connect a new source**, click **Google BigQuery**.
3. Enter a **Name** and a **Key**. The key can't be changed later.
4. Click **Add warehouse**. Knock opens the warehouse's **Details** tab.

## Connect Google BigQuery

1. In the Google Cloud project with your data, create a service account whose ID starts with the prefix shown on the **Details** tab, and give it the BigQuery User and BigQuery Metadata Viewer roles on the project. The prefix is unique to your Knock account. Knock needs BigQuery Metadata Viewer to list your tables when you create a sync, and it has to be granted on the project because one warehouse can sync tables from more than one dataset.
2. Give the service account the BigQuery Data Viewer role on each dataset you'll sync.
3. On the service account's **Principals with access** tab, give Knock's service account, shown on the **Details** tab, the Service Account Token Creator and Service Account User roles.
4. Fill in the connection and click **Save connection**:

   | Field                 | What to enter                                                     |
   | --------------------- | ----------------------------------------------------------------- |
   | Project ID            | The Google Cloud project with your data, such as `acme-analytics` |
   | Data location         | Where your datasets are, such as `us` or `us-central1`            |
   | Service account email | The service account you created for Knock                         |

5. Click **Test connection**.

Knock only sees datasets in the data location you enter.

Once the connection works, [create a sync](/integrations/sources/syncs#create-a-sync) to start syncing data into Knock. If you map a `DATETIME` column to a user's `created_at`, you'll need to convert it to `TIMESTAMP` first. See [timestamps](/integrations/sources/syncs#timestamps) for more information.
